# Global Dengue Observatory

The Global Dengue Observatory is run by researchers at the [London School of Hygiene & Tropical Medicine](https://www.lshtm.ac.uk). We aggregate reported dengue case data from countries, combine them with models for reporting delay and seasonality, and publish estimates of the current situation at national, regional, and global levels—to support public health decisions and public awareness.

This repository holds the source for our [Quarto](https://quarto.org) website (pages, figures, and R code), the data processing pipeline under `Scripts/`, and pipeline outputs under `Output/`. A scheduled workflow refreshes pipeline outputs on the default branch. Please visit [globaldengueobservatory.org](https://globaldengueobservatory.org/) for the live site, data downloads, methods, and team information.
